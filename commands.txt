小米 / Redmi / POCO 隐私组件：可直接复制的 ADB 命令
（不想用脚本时用这个。Windows 请在 PowerShell 里执行，不要用 cmd，否则 # 开头的说明行会报错；Mac / Linux 在终端里执行。可以整段复制粘贴。）

先确认连上了：adb devices   （能看到一串编号 + device 才行）
手机上没有的包会返回 Failure [not installed for 0]，可以忽略。

==================== A 隐私上报（建议删） ====================
adb shell pm uninstall --user 0 com.mobiletools.systemhelper
    # 联通终端管理 SystemHelper：据逆向报告，会定期上报 App 使用清单、使用时长和流量、IMEI/IMSI/ICCID、基站和位置，插任何运营商的卡都会触发。删后请确认两张卡都能正常打电话、上网
adb shell pm uninstall --user 0 com.miui.analytics
    # 小米统计 Analytics：后台统计和数据上传
adb shell pm uninstall --user 0 com.miui.daemon
    # 系统守护 MiuiDaemon：后台收集系统和性能数据
adb shell pm uninstall --user 0 com.miui.misightservice
    # 系统质量监测 MiSight：向小米上报系统事件日志。注意：系统底层另有一个 root 权限的 misight 进程，删 App 不一定能关掉它
adb shell pm uninstall --user 0 com.xiaomi.security.onetrack
    # 手机管家数据上报 OneTrack：手机管家的行为埋点上报模块
adb shell pm uninstall --user 0 com.miui.bugreport
    # 错误报告 / 用户反馈：打包上传错误日志；删后不能用系统自带的反馈功能
adb shell pm uninstall --user 0 com.miui.uireporter
    # 界面事件上报：上报界面崩溃和交互事件

==================== C 运营商注册组件（按需删，删后测试通话、上网、支付） ====================
adb shell pm uninstall --user 0 com.miui.dmregservice
    # 中国移动 RegService：插移动卡时每 7 天上报 App 清单、使用时长和流量。有精简清单称删后可能影响开机激活、移动网络或支付，出问题就恢复
adb shell pm uninstall --user 0 com.xiaomi.registration
    # 中国电信自注册：电信卡终端注册；有开发者检查称它不上传 App 清单，删除后的影响未知

==================== E 高风险（默认不建议；要删就一次只删一个，重启测试） ====================
adb shell pm uninstall --user 0 com.miui.guardprovider
    # 系统安全组件：就是这次被指录屏上传、上报第三方 App 清单、做 AI 通话检测的组件。删后可能无法安装或更新 App、手机管家反复报错，个别机型有卡开机的报告；HyperOS 3 上可能免 root 删不掉
adb shell pm uninstall --user 0 com.miui.contentcatcher
    # 应用程序扩展服务（内容捕获）：有清单称它抓取屏幕内容，但能否安全删除说法冲突，有人称删后卡开机

==================== 恢复（把包名换成要恢复的那个） ====================
adb shell cmd package install-existing --user 0 包名
例如：adb shell cmd package install-existing --user 0 com.mobiletools.systemhelper

查看某个包还在不在：adb shell pm list packages | findstr 包名      （Mac / Linux 把 findstr 换成 grep）
